# Module 15 — Cloud / Cloud@Customer / Multicloud

## Objectif

Comparer les modes de déploiement Exadata selon contraintes métier, réseau, souveraineté, exploitation et coût.

## Scénarios

- Exadata X11M on-premises ;
- Exadata Cloud@Customer ;
- OCI Exadata Database Service ;
- architectures hybrides ;
- intégrations multicloud lorsque pertinentes.

## Critères

- localisation des données ;
- latence applicative ;
- dépendance réseau ;
- responsabilités d’exploitation ;
- patching ;
- capacité ;
- élasticité ;
- PRA ;
- sécurité ;
- conformité ;
- coût ;
- réversibilité.

## Questions

- où sont les applications ?
- où sont les utilisateurs et systèmes partenaires ?
- quelle dépendance WAN est acceptable ?
- quel niveau de contrôle infrastructure est requis ?
- comment assurer le DR ?
- quelles responsabilités restent côté client ?

## Livrable

Matrice multicritère On-Prem / Cloud@Customer / OCI / Hybride avec recommandation argumentée.
