# Module 12 — Security / TDE / Wallet

## Objectif

Construire une architecture de sécurité couvrant données, administration, réseau, clés et preuves d’audit.

## Domaines

- TDE ;
- Wallet / keystore ;
- rotation et sauvegarde des clés ;
- séparation des rôles ;
- moindre privilège ;
- bastion ;
- segmentation réseau ;
- audit ;
- durcissement OS ;
- SELinux ;
- certificats ;
- secrets ;
- comptes techniques ;
- accès support.

## Questions d’architecture

- qui contrôle les clés ?
- où sont sauvegardés les wallets ?
- comment récupérer après perte du site ?
- quels administrateurs peuvent accéder à quoi ?
- comment tracer les actions privilégiées ?
- quels flux d’administration sont autorisés ?
- quelle dépendance PKI/LDAP ?
- comment intégrer les exigences réglementaires internes ?

## Livrables

- security architecture ;
- matrice des rôles ;
- matrice de flux ;
- cycle de vie des clés ;
- procédures d’urgence ;
- contrôles et preuves d’audit ;
- risques résiduels.
