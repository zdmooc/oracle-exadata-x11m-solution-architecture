# Module 17 — Green IT / Capacity Efficiency

## Objectif

Évaluer l’efficacité de la capacité Exadata sans réduire l’analyse à un simple ratio kgCO2e/Go.

## Axes

- capacité provisionnée vs utilisée ;
- données actives vs historiques ;
- CPU allouée vs réellement consommée ;
- consolidation ;
- taux d’utilisation ;
- croissance ;
- rétention ;
- stockage HC/EF/XT selon profil ;
- suppression ou archivage de données ;
- dimensionnement N et N-1.

## Point d’attention

Une allocation carbone uniquement proportionnelle au volume de stockage peut masquer la réalité d’usage. Deux applications occupant le même volume peuvent avoir des profils très différents : activité I/O, CPU, redondance, sauvegarde, rétention et fréquence d’accès.

## Livrables

- indicateurs de capacité utile ;
- données actives/inactives ;
- taux d’utilisation ;
- scénarios de consolidation ;
- recommandations de right-sizing ;
- limites méthodologiques des calculs carbone.
