# Diagrams

Les schémas doivent expliquer une décision d’architecture.

## Diagrammes minimum

- contexte système ;
- architecture logique X11M ;
- architecture physique ;
- réseau et zones de sécurité ;
- RAC / Data Guard deux sites ;
- backup / ZDLRA ;
- flux de migration ;
- architecture cible MayaBank.

## Convention

Chaque diagramme doit préciser : périmètre, sites, composants, réseaux, sens des flux, criticité, mécanismes HA/DR et hypothèses.

Préférer Mermaid pour les diagrammes versionnables et Draw.io lorsque le niveau de détail nécessite un éditeur graphique.
